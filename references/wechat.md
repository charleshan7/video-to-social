# 公众号排版规范

## 硬约束

**JS 一律被剥掉。** 交互式时间轴、可折叠脑图、滚动动画在公众号里全部失效。
网页版设计不能照搬——凡是需要脚本的模块，改成静态版本（编号目录、静态数字组）。

**图片不一定跟着走。** 浏览器全选复制粘贴时，内联 data URI 的图有时能带过去、有时不能。
所以必须同时交付编号好的 `images/`，让用户按序手动补传。

**封面是必需品。** 没有封面发不出去：

- `2100×900` 消息主封面
- `1080×1080` 方形分享封面

封面别拿带烧录字幕的视频帧当底图——压半透明蒙版后原字幕仍会隐约透出，显脏。纯字体设计更稳。

## 默认排版参数

```
中文细体          font-weight: 300
正文              15px / #333333 / line-height 1.8 / text-align: justify
子标题            18px（区间 16~24）
注释小字          12~13px / #666666
两端缩进          padding: 0 16px
重点与金句        品牌色加粗
```

字体只能用系统栈——公众号无法内嵌字体，中文字库也大到不可能内联：

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
             "Hiragino Sans GB", "Source Han Sans SC", sans-serif;
```

## 每段不超过 4 行

15px 字号下手机每行约 21 个中文字，所以 **4 行 ≈ 84 字**。

构建脚本应该逐段体检并打印结果，别靠肉眼：

```python
def dlen(s):
    s = s.replace("*", "")
    cjk = len(re.findall(r"[　-〿一-鿿＀-￯]", s))
    return cjk + math.ceil((len(s) - cjk) / 2)

over = [(sec, dlen(p), p[:24]) for ... if dlen(p) > 84]
print("段落 ≤4 行体检：", "全部合规 ✅" if not over else f"{len(over)} 处超长 ⚠️")
```

## 强调分两级

```
***文字***   品牌色加粗   全文 5~8 处，只给最关键的判断
**文字**     纯黑加粗     关键数字与术语首次出现
```

渲染时必须先处理三星号再处理双星号：

```python
s = re.sub(r"\*\*\*(.+?)\*\*\*", f'<strong style="font-weight:600;color:{B}">\\1</strong>', s)
s = re.sub(r"\*\*(.+?)\*\*",     '<strong style="font-weight:600;color:#1A1A1A">\\1</strong>', s)
```

**品牌色对比度要留意。** Claude 橙 `#D97757` 在白底上对比度约 3.2:1，低于正文推荐的 4.5:1，
所以只适合大字号粗体（金句、章节序号），正文内联少用——这与"收敛用量"的结论正好一致。

## 结构

```
标题
来源框（原视频链接 + 时间地点，放最开头）
导语（带品牌色左边框）
本期内容全景（静态编号目录，01~NN + 时间码）
├ 章节标题（序号用品牌色，标题后不放时间码——目录里有就够了）
├ 人物图 + 图注
├ 正文段落
└ 金句（品牌色，左边框）
写在最后
版权与说明
```

**章节标题后不要挂时间码**：读者不会为某一节专门跳原片，它只是重复目录信息，还会挤占标题导致换行。

**图注时间码要加括号**：`图02｜说明文字（原片 04:18）`。
用空格分隔会让时间码和正文同级，容易被读成句子的一部分。

## 交付方式

1. Chrome 打开 `article.html`
2. 全选（Cmd+A）→ 复制（Cmd+C）
3. 粘进公众号编辑器
4. 检查图片是否都带过去了，没带的按 `images/` 编号顺序补传
5. 标题栏单独填（正文里的标题只是文首标题）

构建前运行 `python3 scripts/validate_content.py --channel wechat`。构建后检查：

- `article.html`、`article.md` 和 `图片清单.txt` 均存在；
- `images/` 编号连续，图注中的素材 ID 和原片时间码可回查；
- `cover-2100x900.png` 与 `cover-1080x1080.png` 的尺寸正确；
- 图没有被 `object-fit:cover` 裁掉姓名角标。
